### **Гайд по прошивке DMA-карты**  

#### **1. Установка драйверов**  
- Подключите DMA-кабель Type-C к разъему JTAG/CFG/Update для дальнейшей работы.

Как определить? - Данный порт всегда расположен ближе к материнской плате. 
![alt text](https://i.imgur.com/xBg9zk9.png)  
- В папке с драйверами выберите и установите подходящий драйвер для вашей DMA-карты на **СОФТ ПК**. 

Для DMA карт с интерфейсом RS232 > Установка драйвера требуется через zadig \DATA DISTRICT DMA\FlashCard Tooll\zadig 2.9 > Запустите > Option > List All Devices - Устанавливаем Quad RS232-HS (Interface 0)

Для DMA карт с интерфейсом CH347 > Установка драйвера требуется через CH341PAR \DATA DISTRICT DMA\FlashCard Tooll\CH347 Driver\CH341PAR\CH341PAR\DRVSETUP64 - Запускаете и устанавливаете! 
- [Скачать архив](https://pixeldrain.com/u/FXrd1mCK) 
> [!WARNING]
> **Для успешной прошивки DMA-карты и получения её DNA обязательно распакуйте архив в папку. Без этого шага процесс завершится ошибкой!**


#### **2. Подготовка прошивки**  

- Скопируйте вашу прошивку в папку **\Flash Tools**.  
- Убедитесь, что имя файла прошивки соответствует требуемому формату, например:  
  - `pcileech_squirrel_top.bin`  
  - `pcileech_enigma_x1_top.bin`  

#### **3. Выбор скрипта для прошивки**  
Запустите **один из скриптов** в зависимости от модели DMA-карты:  

| **Модель DMA-карты**               | **Скрипт для прошивки**       |
|-------------------------------------|-------------------------------|
| Captain DMA 75T / Stark DMA 75T / MVP DMA 75T | `flash_ch347_75t`             |
| MVP DMA 35T / LeetDMA 35T / Terminator P1 35T                 | `flash_ch347_35t`             |
| CaptainDMA 3.0 / 4.0 / 4.1 35T   | `flash_rs232_35t`             |
| Screamer M2 R03/R04 35T   | `flash_rs232_35t`             |
| Squirrel PCIe Screamer 35Т   | `flash_rs232_35t`             |
| FPGA 35Т                   | `flash_ch347_75t`   |
| Hack DMA 35Т                   | `flash_ch347_75t`   |
| Ducks 35Т                   | `flash_ch347_75t`   |
| GhostDMA 35Т                   | `flash_ch347_75t`   |

#### **4. Процесс прошивки**  
- Запустите выбранный скрипт и дождитесь завершения процесса.  
- Успешная прошивка подтвердится сообщением **`success`**.

> [!WARNING]
> **Если прошиватор выдает сразу же после запуска скрипта тайминги в секторах 0 ms, а не от 100 до 300 ms значит DMA не прошилась, в таком случае помогает перезагрузка игрового ПК или переподключение USB во 2 пк**


#### **5. Завершение**  
1. **Выключите игровой ПК**.
2. **Перевоткните провод Type-C с разъема JTAG в DATA (Дальний порт Type-C от материнки)** 
3. Подождите **5 секунд**.  
4. **Включите ПК обратно**.  

**Готово!** DMA-карта прошита и готова к работе.
